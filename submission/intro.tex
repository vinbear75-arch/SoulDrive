  SoulDrive（灵枢）是 Windows 本机端侧多模态项目知识工作台，服务“指着实验结果问为什么比上个月差”。它把项目、版本、时间、语音和授权选区组成事件链，先检查指标可比性，再以关键词、向量和图谱检索 E/V/A/M 证据，输出带来源的差异、原因等级和验证实验；证据不足主动澄清或拒答，外部动作须确认。限定评测：30 条产品检索集 all-hit@6 为 90\%（检索指标），10 条真实授权 pilot 目标绑定率为 1.0（非整体准确率）；视觉慢路径仍在优化。系统由 React+Tauri 与 Python sidecar 构成，数据留在本机，公开方法与数据来源逐项标注。
  \end{keybox}
