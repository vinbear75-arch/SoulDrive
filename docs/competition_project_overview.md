# SoulDrive 参赛项目总览

## 一句话定位

用户指着屏幕中的实验结果说“为什么比上个月差”，SoulDrive 在当前项目内对齐语音、授权选区、实验版本和历史偏好，在端侧给出可验证差异、原因证据等级和最小验证实验，并生成带引用的汇报草稿；歧义时先澄清，未经确认不执行外部动作。

## 项目解决什么

SoulDrive 不是普通问答壳，而是一个面向 Windows 本机的项目工作台。它主要解决三类问题：

1. 在同一项目里找到对的材料、对的版本、对的时间。
2. 把屏幕选区、语音指令和项目知识合成一个可追溯的回答。
3. 把已确认的结论变成报告、PPT、任务和沟通草稿。

## 当前已经落地的能力

- 项目空间隔离：项目删除、会话删除后的主会话恢复、项目标题去数量。
- RAG 链路：项目优先检索、全局文档回退、跨项目私有来源隔离、引用与来源定位。
- 实验材料：CSV/XLSX、YAML/JSON、日志、报告、截图和模板可进入同一证据链。
- 多模态链路：语音、UIA、OCR、授权裁剪视觉、时间原点和项目字段已经贯通到 API 和前端事件层；同屏一致内容会合并成协同视觉证据。

## 当前可写进材料的事实

- 本机 Windows PC 运行，不默认依赖云端推理。
- 已有项目内优先检索与全局回退的回归证据。
- 已有结构化实验来源定位和项目作用域评测证据。
- 已有多模态事件时间/项目字段透传回归。

## 不能写成已完成的内容

- 不能把 targeted tests、烟测或单项 smoke 当成整体准确率。
- 不能把局部 pilot 写成真实大规模业务结论。
- 不能把当前工作区外部未公开评测写成已完成成绩。
- 不能把未录制的演示视频写成已交付视频。

## 推荐的参赛叙事顺序

1. 先讲项目是什么、为什么要存在。
2. 再讲项目隔离、RAG 证据链和多模态对齐。
3. 然后讲已验证结果和失败边界。
4. 最后讲演示流程和可复现材料。
