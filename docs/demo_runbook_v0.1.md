# SoulDrive 参赛演示 Runbook（3 分钟主流程）

## 一句话定位

用户指着屏幕中的实验结果说“为什么比上个月差”，SoulDrive 在当前项目内对齐语音、授权选区、实验版本和历史偏好，在端侧给出可验证差异、原因证据等级和最小验证实验，并生成带引用的汇报草稿；歧义时先澄清，未经确认不执行外部动作。

## 演示前准备

1. 使用脱敏演示材料，不放真实姓名、邮箱、密钥或未公开内容。
2. 使用 Windows PC 主路径，不启用 U 盘模式。
3. 确认模型目录存在：SenseVoiceSmall、RapidOCR；需要图表/图标时再确认 Qwen2.5-VL-3B-Instruct。
4. 预先准备 3~5 份属于同一演示项目的论文/实验报告/技术方案。

## 启动

```powershell
D:\AI_AGENTS\SoulDrive-main\启动SoulDrive.bat
```

只使用该启动入口。它会启动本机 Redis/PostgreSQL（若尚未运行）及 SoulDrive 桌面端；不要额外执行 `tauri dev` 或手动启动 sidecar，以免产生重复开发进程。首次启动：在 SoulDrive 界面初始化本地工作区并设置演示口令；之后输入口令解锁。不要在演示视频中展示真实口令。

## 主流程

1. 选择或创建演示项目。
2. 点击“导入文档”，选择 3~5 份脱敏材料。
3. 等待索引状态显示完成，并确认文档列表中的 `indexed` 状态。
4. 按住麦克风，说：`总结我当前选中的实验结论`。
5. 松开录音按钮，保留 WAV。
6. 点击截图/图片按钮，在授权窗口中只选择 SoulDrive 演示窗口或明确选区，不选择整个桌面。
7. 查看多模态结果：ASR 文本、OCR、目标、意图、澄清状态、耗时和隐私边界。
8. 点击发送到知识问答，查看带来源证据的回答。
9. 在产物区选择 2~3 份材料，点击“生成 WPS 演示文稿”，生成 5~8 页 PPT 草案。
10. 打开 PPTX，展示来源、结论和限制。
11. 可选展示沟通闭环：创建邮件或日程草稿，确认后分别通过已配置 SMTP 手动发送，或导出本地 `.ics` 文件。演示前使用脱敏收件人和单独的 SMTP 授权码；绝不展示授权码。

## 项目级 Skill

将一个 UTF-8 的 `SKILL.md` 放入 `D:\AI_AGENTS\SoulDrive-main\runtime\workspace\skills\<技能名>\`。下一次打开 Skill 窗口、发起问答或生成 PPT 时，SoulDrive 会自动发现并同步该文件；不需要重启，不需要增加新的启动脚本。PPT 风格 Skill 需要在文件内容中声明为模板类 Skill，才会出现在“PPT 风格 Skill”下拉框中。

也可以在 Skill 窗口输入 GitHub/Raw URL 下载。下载内容先进入 `skills\.inbox\` 待审核区，检查 `SKILL.md` 后点击“审核通过并启用”；下载的脚本不会自动执行。命令行方式：

```powershell
python scripts/install_project_skill.py --workspace <SoulDrive工作区> --source openai/skills/skills/slides
```

需要在检查后启用时，追加 `--approve`。只接受 HTTPS GitHub 来源或 `owner/repository/path`，不接受任意本地/外部命令源。

## 备用问题

- `从当前选区提取下一步待办`
- `回答当前选区里的关键指标`
- `比较当前实验和上个月的同类实验`

第三个问题应展示“缺少明确历史候选时主动澄清”，不要让系统强行比较。

## 失败降级

| 故障 | 演示动作 |
|---|---|
| 麦克风不可用 | 使用已保存的演示 WAV，说明为回放模式 |
| 截图授权失败 | 使用已保存的演示 PNG，说明为授权截图回放 |
| OCR 失败 | 切换到文本输入并展示“视觉不可用”的诊断 |
| 索引未完成 | 先展示多模态决策卡，跳过 RAG，说明知识库仍在索引 |
| PPT 生成失败 | 展示已生成的本地 PPT 草案和任务日志 |

## 不能在答辩中声称

- 30 条增强集是真人录音；
- 快路径 P95 覆盖完整 RAG/回答；
- 系统可以未经确认发送邮件、写日历、删除文件或控制任意桌面。
