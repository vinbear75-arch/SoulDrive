# SoulDrive 路线图非华为部分审计

审计目标：只检查 `docs/plans/2026-08-29-souldrive-competition-value-roadmap.md` 中除华为赛题措辞外的项目执行项，判断哪些已经可作为参赛材料，哪些仍不能写成“完成”。

## 结论

非华为部分已经完成了大部分“可提交材料”和“可复现代码”工作，但还不能把整条路线图写成完全完成。原因不是文档缺页，而是仍有少数必须依赖真实运行、真实 episode、真实 P95 和最终冻结的门槛没有满足。

## 已完成或已落地

- 参赛主线定位、项目总览、运行与模型、实验与证据、提交清单、参赛文稿总稿、PPT 大纲。
- 项目空间隔离、会话恢复、删除按钮、项目数量展示调整等 UI / 业务收尾。
- 项目优先 RAG、全局回退、来源定位、GraphRAG 路由与证据命名空间约束。
- 多模态事件链路：语音、选区、OCR、时间原点、项目字段、UIA / 视觉慢路径的契约贯通。
- 个性化画像的记录、管理、读取门和评测契约。
- 证据式生成、Playbook、产物 provenance、实验账本和比较门控。
- 已有的后端、前端、Tauri、Python 编译检查与多项定向回归。

## 仍未完成，不能写成“已完成”

- 至少 30 条独立真实多模态 episode 的冻结采集与端到端评测。
- 真实完整模态相对 text-only 的稳定增益证明。
- VLM 慢路径完整回答 P95 小于 5 秒的真实门槛。
- 真实项目/跨应用/跨分辨率/跨说话人的完整覆盖。
- 生产加密工作区重建后的最终验收。
- 最终冻结：代码、模型、配置、数据、随机种子、逐样本结果、演示材料。
- 真实演示视频录制与最终提交包打包。

## 适合现在写进材料的说法

- “已完成可复现的项目工作台、RAG 证据链、多模态事件链路和产物链路。”
- “已完成一批可提交的文档、检查清单和演示脚本。”
- “已完成若干定向回归，但完整竞赛门槛仍需真实 episode 与最终冻结验证。”

## 不适合现在写进材料的说法

- “整条路线图已经全部完成。”
- “完整模态已经稳定满足最终 P95 门槛。”
- “真实多模态业务结论已经可替代正式评测。”
