# SoulDrive 实验与证据说明

## 证据分层

SoulDrive 的答案和文档只接受四类证据：

- `E#`：文档、报告、配置、日志和标准文件。
- `V#`：授权截图或屏幕中可直接观察到的视觉证据。
- `A#`：用户确认过的语音或会议转写。
- `M#`：结构化实验测量和统计结果。

偏好和模板可以参与表达顺序，但不能改写事实本身。

## 现在可以怎么写

可以写成：

- SoulDrive 支持项目优先检索和全局回退。
- 实验指标、配置、日志和报告都能进入同一条来源链。
- 当前系统已经能在项目边界下区分证据、偏好和实验数据。

不能写成：

- 所有检索和回答都已达到最终竞赛门槛。
- 合成集或 pilot 集已经等同于正式大规模业务评测。
- 单项 smoke 可以外推成完整端到端稳定 P95。

## 推荐的实验叙事

1. 先说数据如何冻结。
2. 再说每个指标怎么来的。
3. 然后列清楚哪些是可写进报告的、哪些只能做边界说明。
4. 最后给出人工复核和下一步补数据计划。
