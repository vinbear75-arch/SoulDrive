# SoulDrive 参赛 PPT 大纲

## 第 1 页：封面

- 标题：SoulDrive
- 副标题：项目内证据式多模态工作台
- 一句话定位：用户指着屏幕中的实验结果说“为什么比上个月差”……

## 第 2 页：问题定义

- 项目知识分散。
- 版本与时间容易错。
- 屏幕、语音和文档经常不在同一语义上下文里。
- 产物生成缺乏证据链。

## 第 3 页：系统方案

- 项目空间隔离。
- 项目优先 RAG，必要时全局回退。
- 语音 / 屏幕 / OCR / 视觉 / 项目元数据对齐。
- 报告、PPT、邮件、日程草案统一走证据链。

## 第 4 页：RAG 链路

- 清洗与结构化解析。
- 切片与入库。
- 查询理解与路由。
- 混合检索与重排。
- 受控生成与引用。

## 第 5 页：多模态链路

- 结构化文本快路径。
- 图标 / 图表 / 复杂目标走视觉慢路径。
- 时间原点、项目 ID、选区信息贯通。
- 冲突时先澄清，不盲目执行。

## 第 6 页：已验证结果

- 后端测试通过。
- 前端构建通过。
- Tauri 检查通过。
- 项目作用域检索和全局回退有回归证据。
- 多模态事件字段透传有回归证据。

## 第 7 页：当前边界

- 不宣称外部未公开成绩。
- 不把 smoke / pilot / 合成集写成整体准确率。
- 不把未完成的 P95 或 30 episode 门槛写成已完成。

## 第 8 页：演示流程

- 打开项目空间。
- 说一句带屏幕上下文的问题。
- 展示证据定位与回答。
- 展示草稿 / PPT / 任务输出。
- 用失败分支说明澄清与降级。
