# SoulDrive 图像 OCR 评测规程 v0.1

## 目标

本规程用于验证 PC 端图像输入从“加密导入 → 本地 OCR → 带坐标证据 → 检索问答”的前半链路。它只评估文字感知，不替代图表语义理解或端到端回答质量评测。

建议首轮采集 50 张企业场景图片，控制人工标注成本：

- 软件、网页和业务系统截图 15 张。
- 扫描合同、制度和报告页面 15 张。
- 表格、图表与流程图截图 10 张。
- 模糊、倾斜、低对比度和小字号图片 10 张。

每张图片标注 3–8 个必须识别的短语，并为其中 1–3 个短语标注归一化 bbox。训练、调参和最终报告使用固定版本的数据集，禁止把最终测试图片用于提示词或规则定制。

## JSONL 格式

图片路径相对于 JSONL 文件所在目录：

```json
{"id":"IMG-001","image_path":"images/IMG-001.png","category":"software_ui","expected_terms":["访问控制","审计日志"],"expected_regions":[{"text":"审计日志","bbox":{"x":0.12,"y":0.30,"width":0.22,"height":0.08},"min_iou":0.5}]}
```

评测报告只保存样本 ID 和聚合指标，不保存图片路径或识别全文。

## 指标和首轮门槛

| 指标 | 计算口径 | 首轮目标 |
| --- | --- | ---: |
| Parse Success Rate | 产生至少一个 OCR 证据块的图片占比 | ≥ 95% |
| Term Recall | 命中的人工标注短语数 / 标注短语总数 | ≥ 90% |
| Localization Accuracy@IoU0.5 | 命中短语且 bbox IoU 达标的区域占比 | ≥ 80% |
| OCR P95 Latency | 单张图片解析端到端 P95，包含模型冷启动 | < 2,000 ms |
| Under-5s Rate | 单张 OCR 耗时小于 5 秒的占比 | 100% |

OCR 在索引阶段异步执行，因此单轮应答 `<5s` 还必须另外测量“已索引图片设为当前上下文 → 首 token”和“完整回答”延迟，不能用 OCR 指标代替问答指标。

## 对照与消融

最终材料至少报告三组：

1. 文件名上下文：只使用图片文件名，不使用 OCR。
2. OCR 文本：使用 OCR 文本检索，不使用 bbox 和当前上下文事件。
3. SoulDrive 完整链路：OCR 文本 + bbox 证据 + 带时间戳的当前图片上下文。

除消融变量外，三组必须使用同一批图片、问题、检索深度、嵌入模型和生成模型。至少报告 Term Recall、Evidence Hit@6、引用正确率、首 token P50/P95 和完整回答 P50/P95。
