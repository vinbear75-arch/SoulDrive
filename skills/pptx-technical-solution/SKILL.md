# 技术方案汇报

让评审者能判断方案为什么这样设计、如何运行、风险在哪里以及怎样落地。

## 页面流程

按背景与目标、总体架构、关键流程、风险与边界、落地计划、资料来源组织页面。

## 内容规则

- 架构页区分组件和职责，流程页按先后顺序表达，不把长段代码或原文搬入页面。
- 风险页必须同时给出风险、影响和缓解措施；落地页必须给出阶段、产出和验收点。
- 每个内容页至少绑定一个本地来源文件，证据不足时显式说明。
- 只生成可编辑 PPTX，不执行远端脚本或安装命令。
